# 🌐 WebSumm AI

**Smart website content analysis** — paste any URL and get an AI-powered summary and insights from the page content. Single-file web app, zero build step.

🌐 **Live:** [websumm.vercel.app](https://websumm.vercel.app)

## ✨ Features

- 🔗 Paste a URL, get an instant AI summary
- 🧠 Powered by Pollinations AI (free, no API key needed)
- 🎨 Clean Tailwind UI
- 📄 Single `index.html` — deploy anywhere

## 🛠️ Tech Stack

- **HTML + Tailwind CSS + vanilla JavaScript**
- **Pollinations AI** text API for summarization

## 🚀 Getting Started

```bash
git clone https://github.com/Sugamdeol/Websumm.git
cd Websumm
python -m http.server 8080
```

Open `http://localhost:8080` and paste any URL.
